# Протокол приёмки PV-OPS-04 — v0.4.0

**Это журнал проверок, не акт сдачи.** Состояния: «автоматизирован частично» — есть тест на ключевой инвариант; «не подтверждено» — испытание и его результаты отсутствуют.

| Тест | Назначение | Состояние / доказательство |
| --- | --- | --- |
| AT-01 | 5 повторов одного eventId | Автоматизирован: test_at01_duplicate_event_id |
| AT-02 | Невалидный и oversized batch | Автоматизирован: test_at02_validation_and_quota |
| AT-03 | 40 ошибок при пороге 20 | Автоматизирован: test_at03_at04_one_alert_and_one_incident |
| AT-04 | Рост count без роста числа incidents | Автоматизирован частично; нет реального 5-минутного soak |
| AT-05 | Прекращение heartbeat | Автоматизирован с управлением временем: test_at05_heartbeat_missing_alert |

| AT-11 | SSE reconnect catch-up | Автоматизирована проверка курсора и командного ограничения через streaming generator; сетевой E2E reconnect ещё не подтверждён |
| AT-12 | Postmortem и MTTA/MTTR по timeline | Автоматизирован частично: test_ack_idempotent_team_isolation_postmortem_metrics |

Дополнительно реализованы негативные проверки RBAC, чужого serviceId, CSRF, late event, dry-run replay без записей и уведомлений, Markdown-export postmortem и статистических серий. В v0.2.0 добавлены тесты миграции v1→v2, уникальности активного инцидента, параллельного создания инцидента двумя worker и retention с pending outbox. В v0.3.0 дополнительно автоматизированы опоздавшие события в коротком event-time окне, отложенная обработка будущих событий, фильтры разных fingerprints, метрики очереди, SSE cursor/права и отзыв сессии. В v0.4.0 добавлены проверки пакетной корреляции (сотни записей — одна оценка правила), независимых групп labels, отката при injected failure, параллельного drain двух worker, heartbeat worker и разделения ready/deferred outbox. Интеграционные тесты требуют отдельной PostgreSQL БД `signalharbor_test`.

## Блокеры полной приёмки

- Завершение всех Must требований, включая 180-дневное хранение агрегатов, 365-дневное хранение metadata инцидентов и полноценную проверку отказоустойчивости worker.
- Измерения p95 ingest и detection на документированной машине; отчёт пикового soak. API-метрика detectionLagP95Ms ограничена выборкой до 5000 alert_fired за час и не является результатом AT-10.
- Тесты имитации транзакционного отказа и конкурентного drain добавлены; реальные kill/restart контейнеров, race при ACK/эскалации и отказ PostgreSQL всё ещё не проверены.
- E2E по двум ролям, включая stream reconnect и maintenance.
- Реальные скриншоты/видео из проверенного запущенного окружения.

Нельзя отмечать «выполнено» без реального протокола запуска и результатов. При новых версиях таблица обновляется по фактам.
